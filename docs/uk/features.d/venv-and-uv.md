# Готове віртуальне оточення з uv

- Віртуальне оточення активне в кожній оболонці й під час кожного запуску, тож встановлення ніколи не зачіпають системний інтерпретатор.
- uv уже встановлено, і він використовує власний інтерпретатор образу, не завантажуючи інший; встановлене компілюється в байт-код для швидшого першого імпорту.
- `pyproject.toml` у збірці синхронізується автоматично, а простий список `pip.deps` теж працює.
- pip і setuptools закріплено, тож перезбирання встановлює той самий інструментарій.
